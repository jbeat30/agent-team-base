# 작업 카드

공통 양식, 호출 시 prompt 본문으로 전달
요약이 아닌 파일 경로를 단일 기준으로 사용, 카드와 파일이 다르면 수신자가 작업을 중단하고 차이를 보고

- runId:
- 요청 원문 경로: `.claude-team/runs/<runId>/request.md`
- 기획안 경로·해시: `.claude-team/runs/<runId>/plan.md`, 해시
- 모드: 해당 시 plan | final
- 목표:
- 허용 파일(구체적 경로):
- 금지 파일·영역:
- 담당 요구사항·완료 기준 ID:
- 순서·의존: 선행 작업과 산출물 경로
- 산출물 경로: 해당 시
- 근거 경로: 해당 시 선행 보고·검사 기록·diff 경로
- 재작업 시: 실패 항목 목록과 회차(한도 3회)

## 요청 원문

> request.md의 원문 그대로 첨부
